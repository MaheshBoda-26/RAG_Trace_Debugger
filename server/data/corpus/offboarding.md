# Data Export and Offboarding

Customers can export all their data at any time from Settings → Data Export.
The export is delivered as a ZIP containing CSV files for transactions,
invoices, and contacts, plus a JSON manifest.

On full account cancellation, customer data is retained for **30 days** before
permanent deletion, to allow for reactivation. After deletion, data is not
recoverable.

Export of audit logs is a separate flow documented in `audit_logs.md`.
